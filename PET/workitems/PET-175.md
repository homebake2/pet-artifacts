PUT на бэкенде поддерживает частичное обновление, поэтому FE должен отправлять diff, а не весь объект (иначе теряются параллельные изменения — lost update). Алгоритм: при открытии формы редактирования сохраняется снимок исходных значений (данные, загруженные с сервера); при сохранении текущее состояние формы сравнивается с этим снимком поле за полем с нормализацией под тип — строковые поля (name/notes/breed/color) через !== после trim; числовое/булево (sterilized) через !== без приведения типов; enum-поля (gender/species/habitation) через !== по строковому значению; birth_date — оба значения приводятся к строке YYYY-MM-DD тем же маппером, что и при отправке, и сравниваются как строки (не сравниваются объекты Date напрямую, чтобы не ловить ложный diff). В итоговый diff попадают только реально изменившиеся поля. Если diff пустой — кнопка «Сохранить» неактивна, PUT не отправляется. Полная спецификация — на странице «Редактирование питомца — Frontend».
