Просмотр календаря выполняет один параллельный запрос GET /activities на каждого питомца пользователя, из-за чего число запросов растёт линейно с количеством питомцев. Для MVP это сознательно принятое ограничение. На будущее стоит предусмотреть batch-эндпоинт, принимающий несколько pet_id за один запрос, чтобы не увеличивать нагрузку с ростом числа питомцев.
