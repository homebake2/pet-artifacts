Поле value формы добавления события сейчас не типизировано в зависимости от type: единая Zod-схема применяет одни и те же ограничения (строка, не более 50 символов) ко всем типам события. Нужна per-type схема, синхронная с BE (PET-125): weight — числовой Input, z.coerce.number().min(0.01).max(200), сериализуется в строку с точкой, напр. "4.5" (кг); urine/defecation/vomit/diarrhea — Select с двумя вариантами, z.enum(["normal","abnormal"]); other — текстовый Input, z.string().min(1).max(50). Discriminated union по type: при смене типа поле "Значение" перерисовывается и сбрасывается. Подробности и таблица — на странице "Добавление события — Frontend".
