Сообщения об ошибках backend сейчас захардкожены на русском, хотя приложение поддерживает i18n. Для текущей итерации это принято как норма: клиент показывает свой локализованный текст по коду ошибки, а не по тексту с сервера. Эта задача — низкоприоритетный TODO на будущее: добавить полноценную серверную локализацию сообщений (например, по заголовку Accept-Language). Не блокирует текущую работу.
