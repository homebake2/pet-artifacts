Бэкенд PUT /profile поддерживает частичное обновление, но фронтенд всегда отправляет всю форму целиком (mapFormProfileToUpdate в src/pages/profile-edit/mappers/map-profile.ts не сравнивает с исходными данными из GET /profile).
Алгоритм: 1) сразу после успешного GET /profile зафиксировать полученные значения как baseline (useForm({ defaultValues }) + отдельный initialValuesRef, т.к. defaultValues не гарантированно остаётся неизменным); 2) на submit сравнить текущее значение каждого поля формы (firstName/middleName/lastName/email/phone) со значением в initialValuesRef по значению (не по formState.dirtyFields — dirtyFields остаётся true, даже если пользователь вернул поле к исходному значению); 3) в payload PUT включать только реально изменившиеся поля — пустая строка означает явную очистку, отсутствие ключа — «не менялось»; ни null, ни текущее значение для немодифицированных полей не отправляются; 4) diff-логику реализовать в mapFormProfileToUpdate (принимает текущие значения и baseline, возвращает только diff); POST для создания профиля продолжает отправлять все поля отдельным маппером.
