Данные питомца и список событий на карточке питомца загружаются двумя независимыми запросами. Если запрос событий падает при успешно загруженных данных питомца, блок событий должен показывать собственное degraded-состояние с кнопкой «Повторить», которая перезапускает только запрос событий, не затрагивая уже отображённые данные питомца.
