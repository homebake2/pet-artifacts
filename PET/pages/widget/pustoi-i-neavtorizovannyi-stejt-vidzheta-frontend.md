## Назначение

Страница описывает поведение виджета (любого из трёх размеров — среднего, маленького, большого), когда его нельзя показать в обычном виде: пользователь не авторизован либо авторизован, но у него нет ни одного питомца.

## Условия

Этот стейт показывается вместо обычного содержимого виджета, если на момент последнего успешно подготовленного снимка данных (см. «Данные виджета» на странице [Виджеты главного экрана — Frontend](vidzhety-glavnogo-ekrana-frontend.md)) выполняется хотя бы одно:

* в приложении нет активной сессии (пользователь не авторизован ни в `network`, ни в `local` режиме — включая случай, когда пользователь ранее вышел из аккаунта);
* пользователь авторизован, но список его (не мягко удалённых) питомцев пуст.

## Основной сценарий

1. Виджет показывает единое сообщение о том, что питомцев нет и их нужно добавить, и кнопку «Добавить питомца» — без различения по размеру виджета, кроме масштабирования по доступному месту (маленький виджет показывает более короткий текст сообщения, чем средний/большой, той же сути).

2. Нажатие кнопки «Добавить питомца» открывает приложение:

   * если пользователь авторизован (нет питомцев, но есть сессия) — сразу экран добавления питомца, см. [Добавление питомца — Frontend](../pets/dobavlenie-pitomtsa-frontend.md);
   * если пользователь не авторизован — экран входа/регистрации, см. [Вход и регистрация — Frontend](../auth/vhod-i-registratsiya-frontend.md); после успешного входа/регистрации пользователь автоматически переходит на экран добавления питомца, тем же способом, каким приложение обычно ведёт нового пользователя без питомцев к добавлению первого питомца.

3. Кнопки быстрого действия, список/переключение питомцев и блок ближайших событий (см. [Виджеты главного экрана — Frontend](vidzhety-glavnogo-ekrana-frontend.md)) в этом стейте не отображаются.

## Бизнес-правила и валидация

* Конфигурация виджета (выбранный питомец, см. «Настройка виджета» на странице [Виджеты главного экрана — Frontend](vidzhety-glavnogo-ekrana-frontend.md)) в этом стейте недоступна для выбора — предлагать выбрать питомца, когда питомцев нет, не имеет смысла; конфигурация становится доступной снова, как только у пользователя появляется хотя бы один питомец.

* Этот стейт равнозначен для режимов `network` и `local` — отличие только в том, какая сессия (`network`/`local`) и какой список питомцев проверяются (см. [Локальный режим (dataSource=local) — целевая архитектура хранения](../common/lokalnyi-rezhim-datasource-local-zaglushka.md)); отдельного описания для режима `local` эта страница не требует.

* Как только у пользователя появляется хотя бы один питомец (например, добавлен в приложении, пока виджет был в этом стейте), виджет при следующем обновлении снимка данных возвращается к обычному виду (см. [Виджеты главного экрана — Frontend](vidzhety-glavnogo-ekrana-frontend.md)) без дополнительных действий пользователя.
