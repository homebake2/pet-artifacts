## Назначение

Сайт состоит из небольшого набора статических страниц с общим каркасом: шапка с навигацией, содержимое страницы и подвал.

## Страницы сайта

| Адрес | Страница | Требования |
|---|---|---|
| `/` | О приложении | [Главная страница сайта «О приложении»](glavnaya-o-prilozhenii-saita.md) |
| `/ideas` | Предложения | [Предложения на сайте — Frontend](predlozheniya-saita-frontend.md) |
| `/donate` | Поддержать | [Поддержка проекта на сайте](podderzhka-proekta-saita.md) |

* Заголовок вкладки браузера главной страницы — «PetHealth»; у остальных страниц — название страницы и «PetHealth» («Предложения — PetHealth», «Поддержать — PetHealth»).

* Запрос несуществующего адреса обрабатывается стандартной страницей «не найдено».

## Общий каркас страницы

* Шапка закреплена вверху страницы и остаётся видимой при прокрутке. В ней находятся название и логотип проекта и навигация между разделами сайта.

* Имеется возможность перейти на главную страницу по названию проекта в шапке.

* Имеется возможность перейти на любой раздел сайта из навигации. Текущий раздел визуально выделен и помечен как текущий для вспомогательных технологий. Навигация имеет доступное название «Разделы сайта».

* Если навигация не помещается по ширине, её можно прокрутить по горизонтали; полоса прокрутки не показывается, элементы навигации не переносятся и не обрезаются.

* Содержимое страницы — одна колонка ограниченной ширины, по центру.

* Подвал содержит «© PetHealth» и ссылку «Политика конфиденциальности».

## Индексация поисковыми системами

* Сайт закрыт от индексации: на всех страницах запрещены индексирование и переход по ссылкам, а файл `robots.txt` запрещает обход всего сайта для всех роботов.

## Состояние страниц

* Страницы отдаются как статический контент; персональные данные посетителя (тема, язык, идентификатор пользователя) применяются без превращения страниц в динамические (см. [Контекст приложения на веб-сайте](../config/kontekst-prilozheniya-na-vebe.md)).

* Тексты сайта — на русском языке. Мультиязычность не поддерживается: язык из контекста приложения влияет только на атрибут языка документа.

## Известный пробел в реализации

Ссылка «Политика конфиденциальности» в подвале пока не ведёт на страницу: страница политики конфиденциальности и адрес, на который должна вести ссылка, ещё не определены. Требуется отдельная страница (или внешний документ) и рабочая ссылка на неё.
