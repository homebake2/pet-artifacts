## Назначение

Главная страница (`/`) коротко объясняет, что такое PetHealth, отвечает на частые вопросы пользователей и рассказывает о разработчике. Страница статическая, не содержит форм и не обращается к серверу.

## Содержимое

Страница состоит из трёх блоков в таком порядке:

1. заголовок страницы — «Здоровье питомцев в одном месте»;
2. блок «Частые вопросы»;
3. блок «О разработчике».

## Блок «Частые вопросы»

* Вопросы показаны списком; у каждого вопроса имеется возможность раскрыть и скрыть ответ.

* Одновременно может быть раскрыт любой набор вопросов; по умолчанию все вопросы скрыты.

* Набор вопросов и ответов задан в самом сайте (не приходит с сервера). Обязательные вопросы:

| Вопрос | Содержание ответа |
|---|---|
| Приложение платное? | Нет, приложение бесплатное; развитие можно добровольно поддержать на странице «Поддержать». Реклама есть только в отдельном разделе приложения, который можно открыть по желанию, если хочется помочь проекту, но нет возможности сделать это материально; в остальных частях приложения рекламы нет. |
| Нужна ли регистрация? | Нет. В локальном режиме данные хранятся на устройстве. Регистрация нужна для синхронизации и общего доступа. |
| Как передать питомца другому человеку? | В карточке питомца создаётся код (или QR); новый владелец вводит или сканирует его в своём приложении. |
| Можно ли перенести локальные данные на сервер? | Да, один раз: из локального аккаунта в сетевой, в настройках приложения. |
| Что делать, если я потерял доступ к аккаунту? | Написать на контактную почту поддержки — доступ помогут восстановить. |

* Ответ о рекламе соответствует [Реклама — Frontend](../ads/reklama-frontend.md): реклама показывается только на отдельном экране, который пользователь открывает сам.

* Ответы должны соответствовать требованиям приложения: [Локальный режим](../common/lokalnyi-rezhim-datasource-local-zaglushka.md), [Передача питомца — Frontend](../pets/peredacha-pitomtsa-frontend.md), [Перенос локального аккаунта в сеть](../profile/perenos-lokalnogo-akkaunta-v-set-frontend.md). При изменении этих функций ответы обновляются.

## Блок «О разработчике»

* Содержит короткий рассказ о том, что приложение делает один разработчик, который сам держит питомцев, и что развитие идёт по предложениям пользователей и на добровольную поддержку.

* Блок содержит имя/инициал разработчика в качестве аватара.

## Известный пробел в реализации

* Контактная почта поддержки в ответе на вопрос о потере доступа — заглушка (`test@test.ru`); требуется реальный адрес.
