## Назначение

Мобильное приложение открывает веб-сайт со своим контекстом: темой, языком и идентификатором пользователя. Сайт принимает этот контекст, сохраняет его локально в браузере и применяет тему, чтобы внешний вид сайта совпадал с приложением. Идентификатор пользователя на сайте пока только сохраняется.

## Параметры ссылки

Приложение добавляет к ссылке query-параметры:

| Параметр | Значения | Описание |
|---|---|---|
| `theme` | `light`, `dark` | Тема приложения. |
| `lang` | `ru`, `en` | Язык приложения. |
| `uid` | идентификатор пользователя или `local` | Id пользователя на сервере (claim `id` access-токена) в режиме `dataSource=network`; строка `local` в режиме `dataSource=local`. Если id получить не удалось, параметр не передаётся. |

* Уже имеющиеся в исходной ссылке параметры и фрагмент (`#…`) сохраняются; одноимённые параметры заменяются.

* Значения кодируются как компоненты URL.

## Приём параметров на сайте

* При запросе любой страницы сайта с одним или несколькими из этих параметров сайт сохраняет валидные значения в куки браузера (срок хранения — год, доступны всем страницам сайта) и сразу перенаправляет посетителя на тот же адрес без этих параметров. Остальные параметры ссылки сохраняются.

* Перенаправление временное (не кешируемое браузером): при следующем открытии сайта из приложения с другими значениями куки должны обновиться.

* Значение, не входящее в допустимые, игнорируется и в куки не записывается; параметр при этом всё равно убирается из адреса. Допустимые значения `uid`: `local` или идентификатор из латинских букв, цифр, `_` и `-` длиной до 64 символов.

* Куки с `uid` недоступна клиентскому скрипту сайта.

## Применение темы и языка

* Сохранённая тема применяется ко всему сайту до первой отрисовки страницы, без мигания темы по умолчанию. Если сохранённой темы нет, действует тема по системным настройкам.

* Сохранённый язык определяет язык сайта: тексты, заголовок вкладки и язык документа. Язык, выбранный посетителем в переключателе сайта, приоритетнее языка из ссылки, а новая ссылка с параметром `lang` сбрасывает прежний выбор переключателя. Порядок определения языка и поддерживаемые языки описаны в [Язык и локализация сайта](../web/yazyk-i-lokalizatsiya-saita.md).

* Применение сохранённых значений не делает страницы сайта динамическими: они по-прежнему отдаются как статический контент.
