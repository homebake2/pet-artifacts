## Назначение

«Кондиция» — оценка телосложения питомца (истощение/недобор/норма/избыток/ожирение), редактируемая на табе «Медкарта» экрана «Ведпаспорт». Это не отдельная сущность и не событие — новое nullable поле питомца, живущее и читаемое/изменяемое через уже существующие эндпоинты питомца, без отдельного CRUD и без собственного набора endpoint'ов.

## Модель данных

Питомец получает новую колонку:

```
ALTER TABLE pet ADD COLUMN body_condition text NULL; -- см. справочник значений
```

## Изменения существующих эндпоинтов

* **`GET /pet/{id}`** (см. «Просмотр карточки питомца — Backend») — ответ дополняется полем `body_condition` (строка из справочника либо `null`, если не заполнено).

* **`PUT /pet/{id}`** (см. «Редактирование питомца — Backend») — тело частичного обновления дополняется опциональным полем `body_condition`. Семантика «отсутствие ключа vs явный `null`» — та же, что уже описана для строковых/булевых полей питомца на странице «Редактирование питомца — Backend»: отсутствие ключа — значение не меняется, явный `null` — значение очищается.

Никакие другие эндпоинты (`POST /pet`, `POST /import/local-data`) этой правкой не расширяются автоматически — расширение `POST /pet` полем `body_condition` при создании и расширение импорта описаны отдельно (см. «Кондиция — Frontend» и «Импорт локальных данных — Backend», раздел о переносе Ведпаспорта); эта страница фиксирует только модель данных и правку двух эндпоинтов чтения/редактирования.

## Бизнес-правила и валидация

* `body_condition`, если передано в `PUT /pet/{id}`, должно быть одним из значений справочника «Ведпаспорт — Кондиция» (см. [Справочник значений (словари enum)](../common/spravochnik-znachenii-slovari-enum.md)) либо `null` — иначе `400`, по тому же принципу, что валидация `species`/`gender`/`habitation` питомца.

* Поле не связано ни с одним типом события и не создаёт побочных событий при изменении — в отличие от `weight` (см. «Редактирование питомца — Backend»).

## Обработка ошибок

| Статус | Условие |
| --- | --- |
| 400 | `body_condition` не `null` и не входит в справочник значений |
| 401 | Токен отсутствует или недействителен |
| 404 | Питомец не найден, мягко удалён или принадлежит другому пользователю |
| 500 | Внутренняя ошибка БД |

## Хранение состояния и побочные эффекты

Изменяет только колонку `pet.body_condition`. Побочных эффектов (событий, других сущностей) нет.
