## Назначение

Таб «Аллергии»: список аллергий питомца, экраны добавления/редактирования.

## Основной сценарий

1. Таб открывается запросом списка аллергий — скелетон/пустое состояние по общим правилам (пустое состояние: призыв добавить первую аллергию, кнопка «+ Добавить аллергию» показывается всегда).

2. Список показывает аллергии карточками: аллерген, реакция (если заполнена, как заметка под названием), бейдж степени тяжести («Легкая»/«Средняя»/«Тяжёлая»), иконки «редактировать»/«удалить».

3. «+ Добавить аллергию» / «редактировать» открывают форму: Аллерген (обязательное, ≤100), Реакция (опционально, ≤200, свободный текст — например, «кожная»), Когда выявлена (опционально, без ограничения диапазона), Степень реакции — переключатель из трёх вариантов «Легкая»/«Средняя»/«Тяжёлая» (обязательный, по умолчанию «Легкая» при создании), Заметка (опционально, ≤1000, multiline), блок прикрепления файлов (до 10).

4. «Сохранить» блокирует повторное нажатие и показывает индикатор загрузки; после успеха — возврат на таб «Аллергии» с инвалидацией кэша списка.

## Бизнес-правила и валидация

Обязательные поля: «Аллерген», «Степень реакции».

## Обработка ошибок

| Ситуация | Что делает система |
| --- | --- |
| Не заполнено обязательное поле | Форма не отправляется, сообщение под полем |
| Ошибка сервера при сохранении | Snackbar/alert, форма не закрывается |
| Аллергия уже удалена на другом устройстве | Тихо убрать из списка / «уже удалено» |

## Хранение состояния и побочные эффекты

После создания/редактирования/удаления — инвалидация кэша списка аллергий питомца.
