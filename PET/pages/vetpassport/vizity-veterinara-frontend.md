## Назначение

Секция «Посещения ветеринара» таба «Медкарта»: список визитов питомца, экраны добавления/редактирования.

## Основной сценарий

1. Секция открывается запросом списка визитов — скелетон/пустое состояние по общим правилам.

2. Список показывает визиты карточками: причина визита, «{visit_date} · {clinic}» (без «·» и без клиники, если `clinic` не заполнена), заметка, иконки «редактировать»/«удалить».

3. «+ Добавить» / «редактировать» открывают форму: Дата посещения (обязательная, без ограничения диапазона), Причина визита (обязательное, ≤200), Клиника/врач (опционально, ≤200), Заметка (опционально, ≤1000, multiline), блок прикрепления файлов (до 10).

4. «Сохранить» блокирует повторное нажатие и показывает индикатор загрузки; после успеха — возврат на таб «Медкарта» с инвалидацией кэша списка визитов.

## Бизнес-правила и валидация

Обязательные поля: «Дата посещения», «Причина визита».

## Обработка ошибок

| Ситуация | Что делает система |
| --- | --- |
| Не заполнено обязательное поле | Форма не отправляется, сообщение под полем |
| Ошибка сервера при сохранении | Snackbar/alert, форма не закрывается |
| Визит уже удалён на другом устройстве | Тихо убрать из списка / «уже удалено» |

## Хранение состояния и побочные эффекты

После создания/редактирования/удаления — инвалидация кэша списка визитов питомца.
